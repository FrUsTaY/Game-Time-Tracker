**GameTimeTracker** — это легковесное и стильное приложение на Python для автоматического отслеживания времени, проведенного в играх. Приложение работает в фоновом режиме, сидит в системном трее и аккуратно собирает статистику вашей игровой активности.

## ✨ Ключевые возможности

- **Умное отслеживание (Smart Tracking):** Возможность учитывать время только когда окно игры активно (находится в фокусе), с полной поддержкой любых Unicode-заголовков окон и эмодзи.
- **Высокая точность без дрифта:** Точный подсчет времени игровых сессий на базе `time.monotonic()`, исключающий временной дрифт и задержки циклов.
- **Сбор статистики и аналитика:** Подробная статистика с графиками (активность за неделю/месяц, топ игр, средняя продолжительность сессии).
- **Календарь активности:** Просмотр игровых сессий по конкретным дням.
- **Работа в фоне и уведомления:** Сворачивание в системный трей (System Tray), настраиваемые всплывающие уведомления о длительных игровых сессиях и автоматическом обнаружении новых игр.
- **Мгновенная синхронизация вкладок:** Актуализация данных при переходе между вкладками «Мои игры», «Статистика», «Календарь» и «Архив».
- **Автоматическое извлечение иконок:** При добавлении `.exe` файла игры программа сама извлечет его иконку без утечек системных дескрипторов GDI.
- **Защита от потери данных:** Периодический сброс накопленного игрового времени на диск каждые 60 секунд и автоматическая очистка незавершенных («зомби») сессий при перезапуске.
- **Потокобезопасность и стабильность:** Полная изоляция фонового мониторинга и системного трея от графического интерфейса Tkinter через планировщик событий `after()`, корректное завершение процессов и потокобезопасная работа с SQLite (`threading.RLock`).
- **Безопасное резервное копирование:** Создание бэкапа базы данных через SQLite Online Backup API на лету без блокировок и повреждения данных.
- **Архивация игр:** Возможность скрыть старые или удаленные игры в архив, сохраняя при этом всю накопленную статистику.
- **Экспорт данных:** Возможность выгрузки истории сессий в формате CSV.
- **Энергоэффективность и плавность:** Кэширование анимаций и оптимизированная отрисовка Matplotlib с отсутствием утечек памяти и 0% нагрузки на CPU в простое.
- **Современный интерфейс:** Темная тема, стильный UI на базе библиотеки [CustomTkinter](https://github.com/TomSchimansky/CustomTkinter) и графики `matplotlib`.
- **Защита от двойного запуска:** Использование мьютексов предотвращает запуск нескольких копий приложения.

## 🚀 Установка и запуск

Вы можете использовать GameTimeTracker двумя способами: запустить собранный `.exe` файл (просто и быстро) или запустить его из исходного кода.

### Способ 1: Использование скомпилированного .exe (Рекомендуется для обычных пользователей)
1. Скачайте последнюю версию программы из раздела **Releases**.
2. Распакуйте архив в любую удобную папку.
3. Запустите `GameTimeTracker.exe` (или `run_game_tracker.bat`).
4. *Готово!* Добавляйте игры через интерфейс и наслаждайтесь сбором статистики. Приложение может автоматически добавляться в автозапуск Windows (включается в настройках).

### Способ 2: Запуск из исходного кода (Для разработчиков)
Для работы программы потребуется **Python 3.8 или новее**.

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/FrUsTaY/Game-Time-Tracker.git
   cd Game-Time-Tracker
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите приложение:
   ```bash
   python main.py
   ```

## 🛠 Сборка проекта (PyInstaller)

Если вы хотите собрать собственный `.exe` файл из исходников:

1. Убедитесь, что у вас установлен `pyinstaller` (он есть в `requirements.txt`).
2. Запустите скрипт сборки:
   ```bash
   python build.py
   ```
3. Дождитесь окончания процесса. Готовый `.exe` файл будет находиться в папке `dist/GameTimeTracker.exe`.

## 📁 Структура проекта

- `main.py` / `app.py` — Точки входа, инициализация UI и фоновых процессов.
- `tracker.py` — Ядро трекинга. Фоновый поток, мониторинг процессов (через `psutil` и `win32gui`) и отслеживание активного окна.
- `database.py` — Работа с локальной базой данных SQLite (`data/gametracker.db`), индексы и потокобезопасность.
- `tray.py` — Логика работы системного трея (`pystray`).
- `settings.py` — Управление настройками и автозапуском через реестр Windows.
- `utils.py` — Определение базовых директорий приложения и путей к ресурсам (в т.ч. в скомпилированном PyInstaller виде).
- `ui/` — Компоненты пользовательского интерфейса (CustomTkinter):
  - `main_window.py` — Главное окно с боковой панелью.
  - `tab_games.py`, `tab_stats.py`, `tab_calendar.py`, `tab_archive.py`, `tab_about.py` и др. — Вкладки интерфейса.
- `tests/` — Набор модульных и интеграционных автотестов (`unittest`).
