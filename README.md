**GameTimeTracker** — это легковесное и стильное приложение на Python для автоматического отслеживания времени, проведенного в играх. Приложение работает в фоновом режиме, сидит в системном трее и аккуратно собирает статистику вашей игровой активности.

## ✨ Ключевые возможности

- **Умное отслеживание (Smart Tracking):** Возможность учитывать время только когда окно игры активно (находится в фокусе), с полной поддержкой любых Unicode-заголовков окон и эмодзи.
- **Пауза при бездействии (AFK):** Если вы отошли и мышь/клавиатура неактивны дольше заданного порога, время не начисляется — статистика не «накручивается» оставленной открытой игрой. Включается в настройках (по умолчанию выключено, чтобы не мешать играм с геймпадом).
- **Дневной лимит игрового времени:** Настраиваемый общий лимит с однократным напоминанием за день — бережёт от «ещё одной катки».
- **Лимиты по отдельным играм:** Можно задать индивидуальный дневной лимит для конкретной игры (например, 60 минут мультиплеера) — уведомление придёт один раз в день.
- **Еженедельная сводка:** Раз в 7 дней приходит ненавязчивое уведомление с итогами: сколько времени, топ-игра, активные дни, серия. Отключается одной настройкой.
- **Ненавязчивые уведомления и центр уведомлений:** Обнаружение нового процесса больше не перехватывает фокус и не всплывает поверх запущенных игр. Показывается системное уведомление в трее (с возможностью добавить игру по клику). Пропущенные уведомления сохраняются в центре уведомлений и доступны через колокольчик `🔔 Уведомления` в главном окне.
- **Интеллектуальная фильтрация процессов:** Автоматическое обнаружение реальных игр с окном и диалогом добавления. Полное исключение системных процессов Windows, браузеров и мессенджеров.
- **Постоянное сохранение «Не отслеживать»:** Решение отказаться от отслеживания процесса надёжно сохраняется в базе данных. В окне «Настройки» доступен раздел «Не отслеживаются», позволяющий в любой момент просмотреть список и вернуть нужный процесс в трекинг.
- **Высокая точность без дрифта:** Точный подсчет времени игровых сессий на базе `time.monotonic()`, исключающий временной дрифт и задержки циклов, без отката секунд при переключении между вкладками.
- **Сбор статистики и переключатель «Учитывать архив»:** Подробная аналитика активности с адаптивным прореживанием дат на 30/90 дней (без слипания текста), топ игр, среднее время сессий и рекорды. Добавлен мгновенный переключатель «Учитывать архив», позволяющий считать статистику только по активным или по всем играм сразу.
- **Краткосрочная аналитика:** Карточки «Сегодня», «За 7 дней», «Серия дней подряд» и «В среднем в день» — быстрый ответ на вопрос «как я играю в последнее время».
- **Корректный учёт сессий через полночь:** Длительность сессии распределяется по фактическим дням, поэтому календарь и график активности больше не «съезжают» для ночных игр.
- **HTML-отчёт за период:** Одна кнопка — и готов автономный отчёт за 7/30/90 дней (сводка, таблица игр, активность по дням) для отправки или архива.
- **Календарь активности:** Наглядная сетка с точками активности, неоновой подсветкой активного дня, автосбросом при смене месяцев и грамотным падежом дат («28 сентября 2026 г.»).
- **Работа в фоне без спама:** Сворачивание в системный трей с показом уведомления строго один раз за запуск (без назойливого звона при каждом нажатии на крестик), настраиваемые напоминания о длительных сессиях.
- **Удобное управление библиотекой и умный поиск:** Поиск мгновенно фильтрует карточки и сохраняется при смене сортировки, переименовании, архивации и удалении игр. Пакетное добавление из запущенных с сохранением отмеченных чекбоксов, полноразмерное редактирование названий с отменой по `Esc`, быстрое восстановление игр из Архива и окончательное удаление прямо из архива.
- **Автоматическое извлечение иконок:** При добавлении `.exe` файла игры программа сама извлечет его иконку без утечек системных дескрипторов GDI.
- **Защита от потери данных:** Периодический сброс накопленного игрового времени на диск каждые 60 секунд и автоматическая очистка незавершенных («зомби») сессий при перезапуске.
- **Потокобезопасность и стабильность:** Полная изоляция фонового мониторинга и системного трея от графического интерфейса Tkinter через планировщик событий `after()`, корректное завершение процессов и потокобезопасная работа с SQLite (`threading.RLock`).
- **Синхронизированные настройки:** Сохранение параметров приложения и автозапуска в реестре Windows происходит согласованно при нажатии кнопки «Сохранить и закрыть».
- **Безопасное резервное копирование:** Создание бэкапа базы данных через SQLite Online Backup API на лету без блокировок и повреждения данных. Плюс автоматическая копия при каждом запуске с ротацией последних 7 файлов (`data/backups`).
- **Журнал и диагностика:** Файловый журнал с ротацией (`data/logs/gametimetracker.log`) — ошибки фонового трекера и БД больше не теряются в windowed-сборке.
- **Надёжная работа с SQLite:** WAL-режим, `busy_timeout`, `synchronous=NORMAL` и автоматические миграции схемы (`PRAGMA user_version`) — обновление приложения не ломает существующую базу.
- **Архивация игр:** Возможность скрыть старые или удаленные игры в архив, сохраняя при этом всю накопленную статистику, с возможностью окончательного удаления прямо из вкладки «Архив».
- **Экспорт данных:** Выгрузка истории сессий в CSV, а также полный экспорт/импорт всех данных (игры, время, сессии, лимиты, игнорируемые процессы) в JSON — удобно для переноса на другой компьютер. Перед импортом автоматически создаётся резервная копия базы.
- **Энергоэффективность и плавность:** Кэширование анимаций и настроек, оптимизированная отрисовка Matplotlib с отсутствием утечек памяти и 0% нагрузки на CPU в простое.
- **Современный интерфейс:** Темная тема, стильный UI на базе библиотеки [CustomTkinter](https://github.com/TomSchimansky/CustomTkinter) и графики `matplotlib`.
- **Защита от двойного запуска:** Использование мьютексов предотвращает запуск нескольких копий приложения.
- **Инженерная обвязка:** `pyproject.toml`, разделение runtime/build/dev-зависимостей, конфигурация `pytest`/`ruff` и CI (GitHub Actions: полный набор тестов на Windows, тесты ядра и аналитики на Linux).

## 🚀 Установка и запуск

Вы можете использовать GameTimeTracker двумя способами: запустить собранный `.exe` файл (просто и быстро) или запустить его из исходного кода.

### Способ 1: Использование скомпилированного .exe (Рекомендуется для обычных пользователей)
1. Скачайте последнюю версию программы из раздела **Releases**.
2. Распакуйте архив в любую удобную папку.
3. Запустите `GameTimeTracker.exe` (или `run_game_tracker.bat`).
4. *Готово!* Добавляйте игры через интерфейс и наслаждайтесь сбором статистики. Приложение может автоматически добавляться в автозапуск Windows (включается в настройках).

### Способ 2: Запуск из исходного кода (Для разработчиков)
Для работы программы потребуется **Python 3.8 или новее**.

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/FrUsTaY/Game-Time-Tracker.git
   cd Game-Time-Tracker
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите приложение:
   ```bash
   python main.py
   ```

## 🛠 Сборка проекта (PyInstaller)

Если вы хотите собрать собственный `.exe` файл из исходников:

1. Установите зависимости для разработки/сборки:
   ```bash
   pip install -r requirements-dev.txt
   ```
2. Запустите скрипт сборки:
   ```bash
   python build.py
   ```
3. Дождитесь окончания процесса. Готовый `.exe` файл будет находиться в папке `dist/GameTimeTracker.exe`.
   Параметры сборки хранятся в `GameTimeTracker.spec` (единый источник истины), `build.py` использует его.

## 🧪 Разработка и тесты

```bash
# зависимости для разработки (тесты, линтер, сборка)
pip install -r requirements-dev.txt

# тесты, не требующие GUI и Windows (база, аналитика, настройки, трекер)
pytest tests/test_database.py tests/test_settings.py \
       tests/test_new_features.py tests/test_backlog_features.py \
       tests/test_utils_and_paths.py

# полный набор (Windows, нужен рабочий Tkinter/дисплей)
pytest

# линтер
ruff check .
```

Тесты запускаются автоматически в GitHub Actions: полный набор — на `windows-latest`,
ядро и аналитика (без GUI) — на `ubuntu-latest`, плюс необязательный прогон `ruff`.

## 📁 Структура проекта

- `main.py` / `app.py` — Точки входа, инициализация UI и фоновых процессов.
- `tracker.py` — Ядро трекинга. Фоновый поток, мониторинг процессов (через `psutil` и `win32gui`) и отслеживание активного окна.
- `database.py` — Работа с локальной базой данных SQLite (`data/gametracker.db`), миграции схемы, индексы, потокобезопасность, аналитика по дням, HTML-отчёты и резервные копии.
- `tray.py` — Логика работы системного трея (`pystray`).
- `settings.py` — Управление настройками и автозапуском через реестр Windows.
- `logging_setup.py` — Настройка журналирования с ротацией файлов.
- `pyproject.toml`, `requirements-dev.txt` — Метаданные проекта, dev-зависимости, конфигурация pytest/ruff.
- `AUDIT.md` — Технический и продуктовый аудит: находки, исправления, бэклог.
- `utils.py` — Определение базовых директорий приложения и путей к ресурсам (в т.ч. в скомпилированном PyInstaller виде).
- `ui/` — Компоненты пользовательского интерфейса (CustomTkinter):
  - `main_window.py` — Главное окно с боковой панелью.
  - `tab_games.py`, `tab_stats.py`, `tab_calendar.py`, `tab_archive.py`, `tab_about.py` и др. — Вкладки интерфейса.
- `bugs/` — Документация по аудитам приложения, отчеты по исправлению UX и журнал проверенных гипотез.
- `tests/` — Набор модульных и интеграционных автотестов (`unittest`/`pytest`), включая тесты новой аналитики, миграций, WAL, AFK-паузы и дневного лимита.
- `data/` — Рабочие данные (создаются при запуске): `gametracker.db`, `backups/`, `logs/`.
